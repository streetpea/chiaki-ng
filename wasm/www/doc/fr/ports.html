Ouvrir les ports (sans Home Proxy)

À utiliser seulement si vous jouez sur le site cloud sans Chiaki Home Proxy.

Même principe que la connexion manuelle de chiaki-ng :

Set up chiaki-ng to work outside of your home network

Pourquoi

Sans proxy, c’est le serveur (VPS) qui ouvre TCP/UDP vers votre console. La box doit transférer le Remote Play vers la PS4/PS5.

Avec Home Proxy

Sautez cette page : le PC maison a déjà le LAN. Aucun port à ouvrir.

1. IP fixe pour la console

Réservez une IP DHCP pour la PlayStation dans la box. Sinon les règles NAT cassent après un redémarrage.

Cherchez réservation DHCP + marque du routeur. Chiaki-ng pointe aussi vers ces instructions.

2. Redirection de ports (NAT)

Transférez vers l’IP LAN de la console. Guide par box : portforward.com (fermez les pubs).

Source : chiaki-ng — Port Forwarding. IPv4 uniquement.

  • TCP 9295 est testé avant d’ajouter la console. S’il est fermé, l’ajout est refusé.
  • 9296 / 9297 UDP = vidéo / audio.
  • Découverte WAN peu fiable. Sur PS4, chiaki-ng indique que la découverte distante ne marche pas.

3. IP publique du foyer

Déconnectez un VPN. whatismyip.com — ou :

curl checkip.amazonaws.com

Dans Chiaki-NG Web : + → coller cette IP (pas 192.168.x) → Tester (9295) → Ajouter.

4. CGNAT

Si 9295 reste fermé depuis Internet, l’opérateur fait souvent du CGNAT : pas d’IP publique dédiée. La redirection ne peut pas marcher.

  • Applis chiaki-ng bureau : connexion via PSN.
  • Chiaki-NG Web : pas de holepunch → Chiaki Home Proxy.

5. L’IP publique a changé

Mettez à jour l’hôte sur le site, ou passez au Home Proxy.

Rappel LAN

Chez vous, même Wi‑Fi, Electron ou Node local : n’ouvrez pas ces ports sur Internet.
