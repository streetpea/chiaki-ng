Chiaki Home Proxy

Petit programme sur le PC à côté de la PS4/PS5. Il relais le Remote Play et la découverte LAN. Connexion sortante : aucun port à ouvrir sur la box.

Web only

Masqué dans Electron, qui a déjà le LAN.

Installation

  1. Connectez-vous sur le site (même compte que l’agent).
  2. Paramètres → Config → Chiaki Home Proxy → Télécharger pour Windows ou Linux (macOS si publié).
  3. Lancez le programme, e-mail + mot de passe Chiaki. Laissez la fenêtre ouverte.
  4. Sur le site : Approuver. Confiance 12 h.
  5. La découverte LAN démarre.

Déconnexion dans Config : l’agent ne se reconnecte plus tout seul.

Ce que ça débloque

  • IP 192.168.x depuis Internet
  • Découverte auto PS4/PS5
  • Test 9295 depuis le PC maison
  • Stream sans NAT

Un autre compte Chiaki ne voit pas votre LAN.

Dépannage

  • Approuvez la demande ; en attente, pas de relais LAN.
  • Relancez l’exe après une mise à jour (bannière 1.1+).
  • Pas d’IP console dans Proxy custom.
  • Pare-feu Windows : autoriser l’exe (réseau privé).
