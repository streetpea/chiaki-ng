Modes de connexion

Le navigateur ne parle jamais directement à la PS4/PS5. Un relais POSIX (serveur Node, Electron, ou Home Proxy) ouvre les sockets TCP/UDP.

1. Même réseau local (LAN)

Vous êtes chez vous, sur le même Wi‑Fi / Ethernet que la console.

  • Electron : le relais tourne sur 127.0.0.1. Aucun port à ouvrir sur Internet.
  • Node sur le PC du salon (node wasm/proxy/server.mjs) : idem, tant que le navigateur atteint ce PC (souvent HTTPS LAN).

Découverte UDP (987 / 9302) + session 9295 suffisent en général. Pas de NAT.

2. Site cloud sans Chiaki Home Proxy

Vous ouvrez chiaki.csphere.fr depuis Internet. Le VPS essaie d’atteindre la console lui-même.

Il faut alors la connexion manuelle de chiaki-ng : IP publique + redirection de ports vers la console.

  • Guide : Ouvrir les ports
  • Référence : Remote Connection (chiaki-ng)

Sans NAT

Une IP 192.168.x / 10.x / 172.16–31.x n’est pas joignable depuis le VPS → need home proxy.

L’ajout manuel refuse tant que TCP 9295 n’est pas ouvert (test intégré).

3. Site cloud avec Chiaki Home Proxy (recommandé)

Un petit programme sur le PC à côté de la console se connecte en sortie vers le cloud. Aucun port à ouvrir sur la box.

Navigateur → serveur → agent → LAN → PS4/PS5.

→ Chiaki Home Proxy
