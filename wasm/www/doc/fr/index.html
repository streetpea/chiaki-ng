Set Up Remote Play

Cette section explique comment jouer en Remote Play vers une PS4 / PS5 avec Chiaki-NG Web (navigateur), pas l’appli bureau.

Astuce

Ouvrez cette doc sur l’appareil où vous jouez pour copier-coller les commandes. Site de jeu : chiaki.csphere.fr.

Choisir comment se connecter

SituationQue faire
Même Wi‑Fi que la console, appli ElectronRien à ouvrir. Découverte LAN.
Site cloud depuis InternetChiaki Home Proxy (recommandé) ou ouvrir les ports
Box en CGNATHome Proxy — le holepunch PSN de chiaki-ng n’existe pas dans le navigateur

Détail : Modes de connexion.

Ce que fait le site

  • Compte (e-mail / mot de passe) : consoles et réglages suivent l’appareil
  • Découverte PS4/PS5 (surtout via Home Proxy)
  • Plusieurs consoles et plusieurs ID PSN (base64) sur le même compte Chiaki
  • Masquer / afficher / supprimer une console
  • Enregistrement PIN (Remote Play → Ajouter un appareil)
  • Stream H.264 / H.265, clavier, souris, manette, manette virtuelle
  • Partage du stream (spectateurs)

IPv4 uniquement

Comme le Remote Play PlayStation et chiaki-ng : pas d’IPv6.
