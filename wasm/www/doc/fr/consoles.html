Consoles

Découverte

Bouton rond (FAB) en bas à droite, ou automatique via Home Proxy.

Les cartes montrent PS4 ou PS5, l’état (prête / veille / inconnu) et l’enregistrement.

Général → Discovery = false coupe le scan, même avec le proxy.

Plusieurs consoles

Un seul compte Chiaki peut garder plusieurs consoles. L’ID PSN (base64) se règle dans Paramètres → Config.

Plafond : CHIAKI_MAX_HOSTS (souvent 4).

Paramètres → Consoles

BoutonEffet
MasquerDisparaît de l’accueil
AfficherAnnule le masquage
SupprimerOublie l’enregistrement (clés Remote Play)

Ajouter à la main

  1. + → IPv4 uniquement
  2. Tester TCP 9295 (obligatoire)
  3. Nom, PS4/PS5, PSN optionnel

Sans proxy : IP publique + ports.

Enregistrer (PIN)

Console : Paramètres → Remote Play → Ajouter un appareil. PS5 : ID PSN 8 octets. Aide : psntools.

Réveil

Console enregistrée en veille : bouton Wake (UDP).
