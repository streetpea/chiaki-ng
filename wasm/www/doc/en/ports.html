Open ports (no Home Proxy)

Only if you use the cloud site without Chiaki Home Proxy.

Same idea as chiaki-ng manual remote connection:

Set up chiaki-ng to work outside of your home network

Why

Without the proxy, the server (VPS) opens TCP/UDP to your console. The router must forward Remote Play to the PS4/PS5.

With Home Proxy

Skip this page: the home PC already has LAN access. No ports to open.

1. Static IP for the console

Reserve a DHCP address for the PlayStation on the router. Otherwise NAT rules break after a reboot.

Search DHCP reservation + your router brand. Chiaki-ng also links these instructions.

2. Port forwarding (NAT)

Forward to the console’s LAN IP. Per-router guide: portforward.com (close ads).

Source: chiaki-ng — Port Forwarding. IPv4 only.

  • TCP 9295 is tested before add. If it is closed, add is refused.
  • 9296 / 9297 UDP = video / audio.
  • WAN discovery is unreliable. Chiaki-ng notes that PS4 remote discovery does not work.

3. Home public IP

Disconnect any VPN. whatismyip.com — or:

curl checkip.amazonaws.com

In Chiaki-NG Web: + → paste this IP (not 192.168.x) → Test (9295) → Add.

4. CGNAT

If 9295 stays closed from the Internet, the ISP often uses CGNAT: no dedicated public IP. Forwarding cannot work.

  • Desktop chiaki-ng: Remote Connection via PSN.
  • Chiaki-NG Web: no holepunch → Chiaki Home Proxy.

5. Public IP changed

Update the host on the site, or switch to Home Proxy.

LAN reminder

At home on the same Wi‑Fi, Electron or local Node: do not open these ports on the Internet.
