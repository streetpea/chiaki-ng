Connection modes

The browser never talks to the PS4/PS5 directly. A POSIX relay (Node server, Electron, or Home Proxy) opens TCP/UDP sockets.

1. Same local network (LAN)

You are at home on the same Wi‑Fi / Ethernet as the console.

  • Electron: the relay binds to 127.0.0.1. No Internet ports to open.
  • Node on the living-room PC (node wasm/proxy/server.mjs): same, as long as the browser can reach that PC (often LAN HTTPS).

UDP discovery (987 / 9302) + session 9295 is usually enough. No NAT.

2. Cloud site without Chiaki Home Proxy

You open chiaki.csphere.fr from the Internet. The VPS reaches the console itself.

That is chiaki-ng’s manual remote connection: public IP + port forwarding to the console.

  • Guide: Open ports
  • Official: Remote Connection (chiaki-ng)

Without NAT

A 192.168.x / 10.x / 172.16–31.x address is unreachable from the VPS → need home proxy.

Manual add is refused until TCP 9295 is open (built-in test).

3. Cloud site with Chiaki Home Proxy (recommended)

A small program on the PC next to the console makes an outbound connection to the cloud. No ports to open on the router.

Browser → server → agent → LAN → PS4/PS5.

→ Chiaki Home Proxy
