Consoles

Discovery

Round FAB at the bottom right, or automatic via Home Proxy.

Cards show PS4 or PS5, state (ready / standby / unknown), and registration.

General → Discovery = false stops the scan even with the proxy.

Several consoles

One Chiaki account can store several consoles. The PSN Account ID (base64) is set in Settings → Config.

Cap: CHIAKI_MAX_HOSTS (often 4).

Settings → Consoles

ButtonEffect
HideRemoved from home
ShowUnhide
DeleteForget registration (Remote Play keys)

Add manually

  1. + → IPv4 only
  2. Test TCP 9295 (required)
  3. Name, PS4/PS5, optional PSN

Without proxy: public IP + ports.

Register (PIN)

Console: Settings → Remote Play → Add Device. PS5: 8-byte PSN ID. Helper: psntools.

Wake

Registered console in standby: Wake (UDP).
