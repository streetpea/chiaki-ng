Set Up Remote Play

This section covers PlayStation Remote Play to a PS4 / PS5 with Chiaki-NG Web (browser), not the desktop app.

Tip

Open this documentation on the device you play on for easy copy/paste. Play site: chiaki.csphere.fr.

How to connect

SituationWhat to do
Same Wi‑Fi as the console, Electron appNo ports to open. LAN discovery.
Cloud site from the InternetChiaki Home Proxy (recommended) or open ports
Router on CGNATHome Proxy — desktop chiaki-ng PSN holepunch is not in the browser

Details: Connection modes.

What the site does

  • Account (email / password): consoles and settings follow you
  • PS4/PS5 discovery (especially via Home Proxy)
  • Several consoles and PSN Account IDs (base64) on the same Chiaki account
  • Hide / show / delete a console
  • PIN registration (Remote Play → Add Device)
  • H.264 / H.265 stream, keyboard, mouse, gamepad, on-screen pad
  • Stream sharing (viewers)

IPv4 only

Same as PlayStation Remote Play and chiaki-ng: no IPv6.
